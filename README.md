### 🎓 Student Clearance System
> A digital clearance management system for educational institutions that automates the student clearance process across multiple departments, reducing paperwork and manual tracking.
>
> - 📋 Digital clearance request submission
> - 🏛️ Multi-department approval workflow
> - 📊 Real-time clearance status tracking
> - 📄 Automated clearance certificate generation
> - 👨‍🎓 Student profile management
> - 🔐 Role-based access (Student, Department Head, Registrar)
> - 📈 Clearance analytics and reporting
> - 🔔 Email notifications for clearance updates
>
> **Tech:** React, Firebase (Firestore, Auth, Cloud Functions), Tailwind CSS, React Hook Form
>
> **Firestore Collections:**
> ```javascript
> {
>   students: { studentId, name, email, department, year, clearanceStatus },
>   clearanceRequests: { requestId, studentId, department, status, date, comments },
>   departments: { deptId, name, head, clearanceOfficer },
>   approvals: { approvalId, requestId, approver, status, date, remarks },
>   certificates: { certId, studentId, generatedDate, pdfUrl }
> }
> ```
>

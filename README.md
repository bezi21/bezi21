## 🏆 Featured Projects

### 🚛 FleetOS – Fleet Management System
> A comprehensive fleet management solution for **Mersin Construcom Company** to track vehicles, maintenance schedules, fuel consumption, and driver assignments. Built with **React** and **Firebase** for real-time updates.

**Key Features:**
- 🚗 Vehicle tracking and management
- 🔧 Maintenance scheduling with automated alerts
- ⛽ Fuel consumption monitoring
- 👨‍✈️ Driver assignment and performance tracking
- 📊 Real-time analytics dashboard
- 🔐 Firebase Authentication with role-based access

**Tech:** React, Firebase (Firestore, Auth, Cloud Functions), Tailwind CSS

**Repository:** [🔗 Mersin-web](https://github.com/bezi21/Mersin-web)

---

### 🏨 Damot Hotel Management System
> A complete hotel management platform that streamlines room bookings, guest check-ins/outs, payments, and staff management. Designed to improve operational efficiency for hotels and resorts.

**Key Features:**
- 🛏️ Room inventory and availability management
- 📅 Online booking and reservation system
- 👤 Guest check-in/check-out management
- 💳 Payment processing and invoicing
- 👨‍💼 Staff and role management
- 📊 Revenue analytics and reporting
- 🔔 Real-time booking notifications

**Tech:** React, Firebase (Firestore, Auth, Cloud Functions), Tailwind CSS

**Repository:** [🔗 damot](https://github.com/bezi21/damot)

---

### 🎓 Student Clearance System
> A digital clearance system for educational institutions to streamline student graduation processes. Automates the clearance workflow across multiple departments.

**Key Features:**
- 📋 Department-wise clearance tracking
- 👨‍🎓 Student profile management
- 📊 Real-time clearance status
- 🔐 Role-based access control
- 📱 Responsive design for all devices

**Tech:** React, Django, PostgreSQL, Tailwind CSS

**Repository:** [🔗 student-clearance](https://github.com/bezi21/student-clearance)
